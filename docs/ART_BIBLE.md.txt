# TAIFUN GAME — ART BIBLE
Version 1.0

---

# PROJECT OVERVIEW

Taifun Game is a vertical mobile Telegram Mini App.

Genre:
- satirical action arena
- mobile combat game
- bureaucracy-themed arcade action

Platform:
- Telegram Mini App
- portrait orientation
- one-hand gameplay

Visual style:
- pixel art
- colorful satire
- readable mobile-first visuals
- large expressive characters
- humorous bureaucracy atmosphere

The game starts bright and comedic,
then gradually becomes darker and more oppressive in later levels.

---

# CORE VISUAL PRINCIPLES

The game must feel:

- readable
- expressive
- humorous
- arcade-like
- mobile-friendly
- visually clean

Avoid:
- visual clutter
- tiny details
- realistic proportions
- dark unreadable combat
- noisy compositions

---

# RESOLUTION + SCALE

Sprite scale:
- 64x64 base character sprites

Boss scale:
- 96x96 or 128x128

UI icons:
- 32x32 or 64x64

Portrait gameplay:
- characters must appear large on screen
- silhouettes must remain readable on phones

---

# CAMERA STYLE

Camera should feel:
- close to action
- readable
- compact

Combat should happen:
- near center screen
- with minimal empty space

---

# MAIN HERO

## Character Identity

A tired office worker pushed to the edge by bureaucracy.

NOT:
- superhero
- military fighter
- fantasy warrior

The hero is:
- relatable
- expressive
- slightly exhausted
- rebellious
- comedic but grounded

---

# HERO VISUAL DESIGN

## Appearance

- dark hair
- slightly messy
- office shirt
- tie
- office pants
- black shoes
- briefcase weapon

Optional:
- rolled sleeves
- loosened tie
- tired facial expression

# HERO SILHOUETTE

The silhouette must be instantly recognizable:
- briefcase

# ENVIRONMENT RULES

Backgrounds must use layered parallax:

- sky
- far buildings
- mid buildings
- foreground objects

Avoid:
- giant empty spaces
- over-detailed backgrounds
- noisy compositions

Combat readability is always priority.

---

# UI STYLE

UI style:
- chunky pixel-art mobile UI
- readable buttons
- large touch areas
- strong outlines

UI inspiration:
- mobile RPGs
- arcade action games
- satirical retro UI

---

# UI COLORS

Use:
- cream panels
- red buttons
- yellow highlights
- blue accents

Buttons must:
- feel tactile
- readable on phones
- visually satisfying

---

# FX STYLE

Effects should feel:
- punchy
- comedic
- exaggerated

Examples:
- paper explosions
- stamp impacts
- flying documents
- impact flashes
- damage numbers

---

# LIGHTING STYLE

Level 1:
- bright daylight

Later levels:
- stronger shadows
- moodier lighting
- more contrast

Avoid:
- realistic lighting systems
- heavy shaders
- overcomplicated effects

---

# PIXEL ART RULES

Pixel art should be:
- clean
- readable
- medium detail
- mobile-friendly

Avoid:
- excessive dithering
- blurry rendering
- tiny unreadable details

---

# MOBILE READABILITY RULES

Everything must remain readable:
- on small screens
- in portrait mode
- during movement/combat

Priority:
1. gameplay readability
2. silhouettes
3. UI clarity
4. atmosphere

---

# GENERATION RULES FOR AI

When generating assets:

DO:
- preserve style consistency
- maintain color harmony
- maintain readable silhouettes
- preserve mobile readability

DO NOT:
- switch art styles
- generate realistic art
- generate anime style
- generate low-contrast sprites
- generate noisy backgrounds

---

# OVERALL GAME FEEL

The game should feel like:

"A frustrated office worker fighting through absurd bureaucracy in a satirical pixel-art mobile world."
